# 나정원 — 이력서 · 자기소개서 · 포트폴리오

튼튼한 기반 위에 기능을 쌓는 Unity / C# 클라이언트 개발자 나정원의 소개 사이트입니다.

상단 가운데 토글로 **소개·이력 / 자기소개서 / 포트폴리오** 세 페이지를 좌우로 넘겨 봅니다.

- 포트폴리오 카드·기술 스택 근거는 배포된 포트폴리오 사이트(`https://najungwon.github.io/portfolio/`)의 `data/*.json`을 읽어 그립니다.
- 발표 덱·상세 기술문서는 그 사이트로 이동합니다(새 탭). 포트폴리오를 다시 빌드·배포하면 이 페이지도 자동으로 따라갑니다.
- 주소가 바뀌면 `index.html`의 `PORTFOLIO_BASE` 한 줄만 고칩니다.

로컬 미리보기: `python -m http.server 4700` → http://localhost:4700
